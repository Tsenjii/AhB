## Reproducible, unmerged defects in current main
1. `internal/hub/playground_ui.go`: CSS `button,.btn` rule lacks a final `}`; this can corrupt following button styles. Repair the exact rule and add a CSS balance regression assertion to the existing Dashboard fixture.
2. Same file: `loadModels` calls `await reload()` then unconditionally displays "已刷新模型清單" even if `reload()` catches a failed `/v1/models` HTTP 503. Have `reload()` return success/failure, render `status bad` on failure, and do not overwrite the error.
3. `internal/hub/playground.go`: `json.NewDecoder(io.LimitReader(r.Body,20*1024))` can hide bytes after a valid JSON object padded to the limit. Use `http.MaxBytesReader(w,r.Body,20*1024)` instead, retain the one-object EOF check, and test a valid object plus padding plus an extra byte.
